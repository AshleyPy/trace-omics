# TRACE-Omics release manifest

This release candidate contains:

- the portable core and study-model utilities from the earlier reconstruction package;
- four comprehensive stage scripts recovered from the dissertation code-development history;
- surviving legacy code chunks retained unchanged for provenance;
- the final dissertation analytical specification in machine-readable YAML;
- a study/accession registry and input templates;
- workflow diagrams and Methods-to-code documentation;
- parsing and synthetic core tests;
- explicit reproduction and release-status documentation.

The repository is intentionally conservative about numerical reproduction: missing author-side analytical state is documented instead of reconstructed by guesswork.
