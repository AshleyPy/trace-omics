# Method and software references

The dissertation contains the complete Harvard reference list. Primary implementation documentation used for this package includes:

- mlr3: https://mlr3.mlr-org.com/
- Nested resampling and AutoTuner: https://mlr3book.mlr-org.com/chapters/chapter4/hyperparameter_optimization.html
- mlr3filters: https://mlr3filters.mlr-org.com/reference/index.html
- DESeq2: https://bioconductor.org/packages/DESeq2/
- sva and frozen SVA: https://bioconductor.org/packages/sva/
- neuroCombat R reference-batch implementation: https://github.com/Jfortin1/neuroCombat_Rpackage
- ranger: https://doi.org/10.18637/jss.v077.i01
- pROC: https://doi.org/10.1186/1471-2105-12-77
- PRROC: https://doi.org/10.1093/bioinformatics/btv153
- TabPFN original model: https://openreview.net/forum?id=cp5PvcI6w8_
- R random-number generation: https://stat.ethz.ch/R-manual/R-devel/library/base/html/Random.html

Record the installed package versions when running the analyses. These documentation links identify methods and interfaces; they do not constitute an environment lock or recovered historical tuning archive.
